# 🎬 IMDB Sentiment Analysis (NLP)

## Overview
This project applies NLP techniques to classify IMDB movie reviews as positive or negative.

## 📂 Dataset
- 50,000 movie reviews  
- Binary classification (positive / negative)


## ⚙️ Steps
1. Text preprocessing (cleaning, stopwords removal, stemming)  
2. Feature extraction:
   - BoW  
   - TF-IDF  
   - Word2Vec  
3. Model training and comparison  


## 🤖 Models
- Naive Bayes  
- Logistic Regression  
- SVM  
- KNN  
- Decision Tree  
- Random Forest  
- Gradient Boosting  
- AdaBoost  
- Extra Trees  
- MLP  
- XGBoost  
- LightGBM  
- Passive Aggressive  

---

## 📊 Evaluation
- Metric: Accuracy  
- Compared models using BoW, TF-IDF, and Word2Vec  

---

## 🏆 Results
- TF-IDF performed best  
- Logistic Regression & SVM achieved highest accuracy  
- KNN & Decision Tree performed worst
